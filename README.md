# Trip Ledger

An offline, private trip budget tracker for Android, Windows and Linux.

Set a trip's dates and budget, record spending the way that suits you —
a running total, the money you have left, or what you spent each day — and
see how much you can spend per day for the rest of the trip.

- **Offline and private.** Trips are stored on your device. Nothing is sent
  anywhere unless you export a trip file and send it yourself.
- **Share a trip as a file.** Anyone with the app can import it. If they
  already have that trip, importing replaces their copy, after showing exactly
  what will change.
- **Versions.** Every import and export is saved as a version, and so is the
  state before anything destructive, so you can always switch back.

## Getting the apps

GitHub → **Actions** → run *Build Android APK*, *Build Windows installer* or
*Build Linux AppImage*, then download the file from the run's page.
